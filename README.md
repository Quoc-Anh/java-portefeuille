# Portefeuille d'actions en Java

Projet réalisé pendant ma formation Java.

## Fonctionnalités

- Ajouter et rechercher une action.
- Acheter et vendre des quantités.
- Retirer une action du portefeuille.
- Calculer la valeur totale du portefeuille.
- Valider les prix et les quantités.

## Notions utilisées

- Classes et encapsulation.
- Collections ArrayList.
- Conditions, boucles et méthodes.

## Exécuter le bilan pratique
