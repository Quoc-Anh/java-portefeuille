# Portefeuille d'actions en Java

Projet réalisé pendant ma formation Java.

## Fonctionnalités

- Ajouter et rechercher une action.
- Acheter et vendre des quantités.
- Retirer une action du portefeuille.
- Calculer la valeur totale du portefeuille.
- Valider les prix et les quantités.

## Notions utilisées

- Classes et encapsulation.
- Collections ArrayList.
- Conditions, boucles et méthodes.

## Exécuter le bilan pratique

Depuis le dossier exercices :

```bat
javac *.java
java BilanSemaine02
```
## Organisation du projet

- exercices/Action.java : représente une action et ses opérations.
- exercices/Portefeuille.java : gère la collection d'actions.
- exercices/BilanSemaine02.java : exécute le bilan pratique.
- exercices/PremiersObjets.java : présente les premiers objets.
- exercices/TestPortefeuille.java : vérifie le fonctionnement du portefeuille.
